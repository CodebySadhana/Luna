# Luna

Luna is a marketing intelligence agent, not a content generator.

Read [`AGENTS.md`](AGENTS.md) — it is the complete ruleset, and it applies to
agents working on this repository as well as to agents running Luna.

## Working on this repo

**`skills/*/SKILL.md` is the only place behavior is written.** Everything in
`commands/`, `.opencode/`, `.cursor/`, and `.agents/rules/` is generated by
`scripts/sync_adapters.py`. Never edit a generated file — run the script.

**`luna/`** holds the deep reference the skills point into: `soul/` (ladder,
principles, voice, scoring, orchestration), `minds/` (the ten), `platforms/`,
and `memory/`.

## Before committing

```bash
python scripts/sync_adapters.py
python -m unittest discover -s tests
```

## The two rules that are not style preferences

1. **First names only** for the ten minds. No surnames, no identifying
   detail. This is the legal line.
2. **Never invent a number.** No performance figure, engagement rate, or
   benchmark result that was not measured or reported. A hedged fabrication is
   still a fabrication.

Both are enforced by `tests/test_integrity.py`.

## Voice

Short. Sharp. Certain. Verdict first, reasoning after. No hedge stacks, no
praise-sandwich. If a paragraph survives with every noun swapped, delete it.
