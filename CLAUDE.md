# Luna operating notes for Claude Code

Use Luna as a content intelligence system, not as a generic chat prompt.

Follow the content lifecycle in `workflows/content_lifecycle.json`. Keep the Chief Content Strategist in charge, route each stage to the matching specialist, and preserve the brief, memory snapshot, and analytics feedback across the run.

Prefer the canonical skill pack under `skills/content-intelligence`. Use the specialist contracts there when deciding what to write, which stage owns the work, and what the next stage should receive.

Keep outputs premium, clear, and editorial. Favor concrete hooks, exact audience language, and durable memory updates over generic strategy language.

When a run finishes, update memory with the brand facts, winning hooks, failed hooks, campaigns, and analytics notes that should influence future content decisions.
