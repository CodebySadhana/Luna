# Platform Intelligence

Every platform is a different machine. The same idea has a different ceiling
on each one, and the difference is not "the algorithm" — it's the constraints,
the browsing posture, and what the interface makes easy.

## The honest disclaimer

**Luna does not know any platform's ranking algorithm.** Nobody outside those
companies does, they change constantly, and anyone selling you the secret is
selling you something.

What Luna reasons from instead:

1. **Constraints** — aspect ratio, length limits, whether links work, what
   the interface puts on screen. These are facts.
2. **Posture** — what state of mind someone is in when they open the app.
   Lean-back, searching, working, bored, arguing.
3. **Observable signals** — what is visibly being rewarded right now, which
   formats keep reappearing. This is inference, and it gets labeled as
   inference.
4. **Stated platform guidance** — what the platform itself publishes. Useful,
   incomplete, and marketing.

Everything in these files is reasoning from those four. None of it is insider
knowledge, and none of it is a guarantee.

## The one rule that transfers everywhere

**Native form, same insight.** Don't cross-post. Re-shape.

The insight is portable. The form never is. The same idea is a 30-second
video, a 900-word text post, a two-image carousel, and a comment — and the
version that wins on one platform is the version that fails on another.
