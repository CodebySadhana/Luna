# The Luna Score

A structured way to argue with an idea before it costs you anything.

## What this is not

**It is not a prediction.** These are heuristic judgments, made by a language
model, about how an idea is *built*. They are not forecasts of reach,
engagement, or revenue. Nothing here has been validated against outcome data,
and a 94 does not mean a piece will outperform an 82.

The score is a **structured argument**, not a measurement. Its value is that
it forces the weak dimension into the open. Two people who disagree about an
idea usually disagree about exactly one dimension — this finds it in seconds.

Treat any score as: *"here is where this idea is strong and where it is thin."*
Nothing more.

## The dimensions

Score 0–100. Fourteen available; **use only the ones the format actually
depends on** — a LinkedIn text post has no production-feasibility problem
worth scoring, and padding the table with 90s you didn't think about is fake
precision.

| Dimension | The question |
|---|---|
| **Attention** | Does it interrupt? Is there a reason to stop in the first 2 seconds? |
| **Novelty** | Have they seen this exact thing this month? |
| **Emotion** | What is the feeling, and how strong? Name it. Mild interest scores low. |
| **Curiosity** | Is there an open loop the viewer needs closed? |
| **Shareability** | What does sharing this say about the sharer? |
| **Saveability** | Would someone return to it? Reference value, not entertainment value. |
| **Retention** | Does the middle earn the end, or does the hook spend everything? |
| **Cultural timing** | Is this the right week? Too early is invisible, too late is derivative. |
| **Audience relevance** | Does the named audience situation actually have this problem? |
| **Brand fit** | Would ten of these teach someone what you stand for? |
| **Differentiation** | Could a competitor post this unchanged? |
| **Production feasibility** | Can one person make this well, this week, with what they have? |
| **Distribution potential** | Is there a real mechanism for it to travel, or just hope? |
| **Conversion potential** | Does it move anyone toward the thing you sell? Not every piece should. |

## Scoring discipline

- **Below 70 is normal.** If most dimensions land in the 90s, you're
  flattering the idea, not scoring it. A useful table has range.
- **The lowest score is the finding.** Lead with it. The 94s are noise.
- **Never score a dimension you didn't think about.** Omit it instead.
- **The overall is a judgment, not an average.** A 30 on Attention caps the
  whole idea regardless of what the rest look like — nothing downstream of an
  unread post matters.

## Output format

```
IDEA  "The productivity advice that makes smart students less productive"

ATTENTION .............. 92
NOVELTY ................ 87
EMOTION ................ 74   ← recognition, not outrage. Lower ceiling.
CURIOSITY .............. 95
SHAREABILITY ........... 88
CULTURAL TIMING ........ 71
BRAND FIT .............. 94
DIFFERENTIATION ........ 90
PRODUCTION ............. 96

LUNA SCORE ............. 88 / 100
VERDICT ................ MAKE IT

Weakest link: cultural timing. This is an evergreen frame with no reason to
be published this specific week. Publish it, but don't count on a spike —
and don't blame the idea if there isn't one.

Heuristic judgment, not a prediction.
```

## Verdict thresholds

| Range | Verdict | What to do |
|---|---|---|
| 85+ | **MAKE IT** | Go. Fix the weakest link first if it's cheap. |
| 70–84 | **REWORK IT** | One dimension is dragging. Name it, fix that one thing, re-score. |
| Below 70 | **KILL IT** | Or find the one salvageable element and start a new idea from it. |
| Attention < 60 | **KILL IT** | Regardless of total. Nothing survives not being seen. |
| Differentiation < 50 | **KILL IT** | Regardless of total. You're making someone else's content. |

The last two rows are hard gates. They override the total.

## Comparing ideas

When scoring a batch, rank them and **cut the bottom half**. A list of ten
ideas where all ten are "worth trying" is not a strategy, it's a menu.

The output of scoring a batch is: what to make first, what to make later,
what to delete.
