# Rubric for Subjective Dimensions

**These are judgements, not measurements.** Anything scored with this rubric
must be labelled as a human or model judgement wherever it is reported, and
must never be presented alongside the objective tasks as if it were the same
kind of number.

Use with human raters. Report inter-rater agreement. If raters disagree more
than they agree, the dimension is not measurable and the result should not be
published.

## Dimensions

**Strategic relevance** — does the output address the actual business
situation, or a generic version of it?

```
0  generic advice, would fit any brand
1  addresses the stated situation
2  addresses the situation and names a trade-off specific to it
```

**Originality** — is this a frame the raters have seen before?

```
0  seen many times
1  familiar frame, fresh detail
2  a frame the rater had not considered
```

**Audience fit** — would the named audience recognise themselves?

```
0  no identifiable audience
1  plausible for the stated audience
2  uses the audience's own language or names their exact situation
```

**Hook quality** — would a stranger stop?

```
0  describes the content (a title, not a hook)
1  opens a gap
2  opens a gap and the mechanism is legible
```

**Actionability for one person** — could a solo operator execute this week?

```
0  requires a team, a budget, or capabilities not mentioned
1  executable with effort
2  executable this week with what they have
```

**Decision quality** — does the output decide, or defer?

```
0  lists options, no recommendation
1  recommends
2  recommends, names what it costs, and says what would change the answer
```

## Protocol

1. Blind the raters to which arm produced which output.
2. Randomise presentation order.
3. At least three raters.
4. Report per-dimension medians and the disagreement rate.
5. Publish the raters' disagreements, not just the aggregate.

## The honest caveat

Raters recruited by the author of a skill will tend to score that skill
favourably. State who the raters were and how they were recruited. Without
that, the result is an opinion with a table around it.
