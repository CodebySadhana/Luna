# Luna Repurpose

David and Olivia. The highest-leverage move available to someone with no time:
one insight, several native forms.

## The rule

**Same insight. Native form. Never the same artifact.**

Cross-posting is not repurposing. A vertical video posted to LinkedIn, a
watermarked TikTok on Reels, a thread pasted as a caption — each says "I made
this for somewhere else," which is the one thing that reliably suppresses a
piece.

## What actually transfers

| Transfers | Doesn't |
|---|---|
| The insight | The format |
| The specific detail or number | The length |
| The point of view | The hook (rewrite every time) |
| The proof | The pacing |
| The story | The ending |

**The hook is always rewritten.** A hook is tuned to one posture and one set
of constraints. A LinkedIn opener fails on TikTok and vice versa — not
slightly, completely.

## The tiers

Repurposing is not ten equal outputs. It is one flagship and several
derivatives, each cheaper than the last.

```
FLAGSHIP     the fullest version. Most expensive. Made once.
             (long video, deep post, newsletter)

NATIVE       genuinely re-made for a second platform. Real work.
             (the short vertical, the LinkedIn post)

EXTRACT      a complete small piece that stands alone.
             (one slide, one quote card, one 20s clip)

ATOM         a reply, a comment, a single line. Nearly free.
             (and the most-skipped tier — atoms are where small
             accounts actually get discovered)
```

## The honest limit

**Not every idea makes ten pieces.** Some make two. Forcing an idea across ten
surfaces produces eight thin pieces and dilutes the two good ones.

If it makes three, say three. Padding the list is the failure mode of this
skill.

## Direction matters

Big → small is easy and usually right: long video → short → quote → reply.

Small → big requires new material, not stretching. A 30-second video does not
become a 10-minute one by talking slower; it becomes one by adding the depth
that was cut.

## Output

```
INSIGHT     [the one thing that transfers — one line]

FLAGSHIP    [platform, format]
            Hook: "[written]"
            What's in it that only fits here:

NATIVE      [platform, format]
            Hook: "[rewritten — not the same line]"
            What changes: [length, opening, ending]

EXTRACT     [what stands alone, and where]

ATOMS       [2–3 replies/comments/lines, written out]

DON'T       [the platform this idea should not go on, and why]
```

Always include DON'T. Knowing where an idea doesn't belong is half the skill.

## Boundaries

Adapts existing ideas. If the source idea hasn't survived the ladder, don't
repurpose it — repurposing a weak idea produces several weak pieces and
multiplies the cost of the original mistake.
